## Файлы

- [CSV](csv/) — отдельный файл для каждого листа.
- [Графики](figures/) — два изображения из приложенного массива в чёрно-белом виде.

CSV: UTF-8 с BOM, разделитель — запятая, десятичный разделитель — точка. Числовые значения выгружены с исходной точностью. CSV содержат значения ячеек; изображения сохранены в Excel и папке `figures`.
