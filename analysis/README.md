# Анализ гипотез H1–H5

[Материалы для сбора H5: план интервью и учебные примеры](../h5_interviews/README.md). Сгенерированные примеры не изменяют результаты анализа.

[Отчёт с таблицами и графиками](REPORT.md) · [Таблицы CSV](tables/) · [Графики PNG/SVG](figures/) · [Программный код](run_analysis.py)

В представленной таблице H1 и четыре критерия H3 поддерживаются; различие T2 для H2 сохраняется. H4 не поддерживается. Для H5 доступны коды тем, но нет текстов ответов или временного сравнения. В истории исходной сводки есть заголовок о реконструкции, а текущие записи проверки ссылок помечены как макеты; первичное происхождение экспериментальных данных не подтверждено.

## Запуск

Требуется Python 3.12. В корне репозитория:

```bash
python -m pip install -r analysis/requirements.txt
python analysis/run_analysis.py --root .
python analysis/validate_results.py --root .
```

Рекомендуется отдельное виртуальное окружение. Seed — 20261010, 20 000 ресэмплирований. Исходные файлы в `csv/` не изменяются. CSV результатов содержат UTF-8 BOM и числовые значения с десятичной точкой. Пустые числовые ячейки означают отсутствие/неприменимость оценки, а не ноль. Повторный запуск воспроизводит проверенный снимок, закреплённый в `source_sha256.json`; при изменении исходников код останавливается. Для нового массива требуется пересмотреть план, обновить хеши, текст отчёта и выводы. Таблицы являются сохранёнными результатами Python.

`manifest.json` фиксирует исходный коммит, хеши, пакеты, seed и методы. Хеши нормализуют CRLF в LF и сохраняют BOM, чтобы результат не зависел от настроек Git в Windows/Linux; исходные файлы не изменяются. `results.json` содержит ключевые оценки. `validation.json` фиксирует независимые численные проверки, сохранность исходников и целостность файлов. Эти проверки не подтверждают происхождение первичных наблюдений.

В именах переменных `pre`=T0, `post`=T1, `delayed`=T2, `transfer`=TR; `group=1` — программа, `group=0` — сравнение; `quality` — качество проверки, `completeness` — полнота журнала, `requests` — число запросов. Разности всегда программа минус сравнение. `p_holm_primary_family` относится к шести проверкам: H1, H2, четыре критерия H3. Дополнительные семейства поправок названы отдельно. Методы и ограничения описаны в отчёте.
